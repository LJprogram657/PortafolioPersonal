# Portafolio Personal - Alvaro Leonardo Baquero Malagon

Este repositorio contiene el código fuente de mi portafolio personal, desarrollado con tecnologías web modernas y enfocado en rendimiento y experiencia de usuario.

## Tecnologías

- **HTML5 & CSS3**: Diseño semántico y estilos avanzados.
- **JavaScript (ES6+)**: Interactividad y lógica del sitio.
- **PWA (Progressive Web App)**: Instalable y con soporte offline.
- **Microinteracciones**: Animaciones sutiles y feedback visual.

## Características

- **Diseño Responsive**: Adaptable a móviles, tablets y escritorio.
- **Modo Oscuro/Claro**: Preferencia de tema persistente.
- **Filtrado de Proyectos**: Exploración dinámica por tecnologías.
- **SEO Optimizado**: Metadatos Open Graph, JSON-LD y sitemap.

## Instalación y Uso

1.  Clona este repositorio:
    ```bash
    git clone https://github.com/LJprogram657/PortafolioPersonal.git
    ```
2.  Abre el archivo `index.html` en tu navegador o usa un servidor local:
    ```bash
    python -m http.server 8000
    ```
3.  Visita `http://localhost:8000`.
